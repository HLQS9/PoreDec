poredec.frontend.lifter module

本模块基于capstone和pypcode提供了一个基础的代码提升器Lifter。 Lifter可以将机器码指令提升为汇编指令，也可以将基于汇编指令的控制流图提升为基于Pcode指令或伪C代码语句的控制流图。

class poredec.frontend.lifter.Lifter(loader: ELFLoader)[源代码]

基类：object

代码提升器

参数:

loader -- ELF文件加载器，用于加载目标ELF文件

Example:

>>> loader = ELFLoader("test.elf")
>>> lifter = Lifter(loader)
>>> insn = Lifter.disassemble_at(0xADD0)
>>> print(insn) # 打印汇编指令

>>> # 假定已经构建了一个基于汇编的控制流图cfg
>>> high_cfg = lifter.lift_cfg(cfg, target_mode=LiftMode.HIGH)
>>> print(high_cfg.entry.insns[0]) # 打印伪高级语言语句
