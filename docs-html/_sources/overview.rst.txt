PoREDec反编译器概览
=====================


源代码文件结构
---------------------

以下是poredec源码目录结构::

    poredec
    ├── __init__.py
    ├── __main__.py
    ├── models # 数据定义
    │   ├── cfg.py
    │   ├── expr.py
    │   ├── __init__.py
    │   ├── insn.py
    │   ├── lift_mode.py
    │   ├── loop.py
    │   ├── reduce_event.py
    │   └── stmt.py
    ├── frontend # 反编译前端
    │   ├── __init__.py
    │   ├── cfg_builder.py # 任务一：构建控制流图
    │   ├── lifter.py
    │   └── loader.py
    ├── backend # 反编译后端
    │   ├── __init__.py
    │   ├── loop_analyzer.py
    │   ├── structure_converter_mixin.py # 实现了结构化代码生成依赖的API
    │   └── structure_converter.py # 任务二：生成结构化代码
    └── utils # 反编译辅助工具
        └── __init__.py
        ├── display.py

其中 ``CFGBuilder`` 和 ``StructureConverter`` 是本次项目需要实现的两个主要类。


工作流程
---------------

PoREDec反编译器的工作流程如下

.. graphviz::
    :align: center
    :caption: PoREDec工作流程图

    digraph Workflow {
        rankdir=TD
        node [shape=box, style=filled]

        "Binary"   [label="二进制程序" , shape=folder, style="", color=white]
        "Function" [label="目标地址"   , shape=note, style="", color=white]
        "CFG"      [label="控制流图"   , shape=note, style="", color=white]
        "Loop"     [label="循环信息"   , shape=note, style="", color=white]
        "HighCode" [label="(伪)高级语言代码", shape=component, style="", color=white]

        "Loader"
        "Lifter"
        "CFGBuilder"
        "LoopAnalyzer"
        "StructureConverter"

        "Binary" -> "Loader"
        "Function" -> "Loader"
        "Loader" -> "Lifter" [label="函数机器码"]
        "Lifter" -> "CFGBuilder" [label="汇编或P-code代码"]
        "CFGBuilder" -> "CFG"
        "CFG" -> "LoopAnalyzer"
        "LoopAnalyzer" -> "Loop"
        "Loop" -> "StructureConverter"
        "CFG" -> "StructureConverter"
        "StructureConverter" -> "HighCode"
    }
